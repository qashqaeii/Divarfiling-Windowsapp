═══════════════════════════════════════════════════════════════════════════════
۱. حق نشر
═══════════════════════════════════════════════════════════════════════════════

این نرم‌افزار و محتوای آن تحت قوانین حق نشر محافظت می‌شود.
تمام حقوق محفوظ است — divarfiling.ir

═══════════════════════════════════════════════════════════════════════════════
۲. اعطای مجوز
═══════════════════════════════════════════════════════════════════════════════

با نصب و استفاده از این نرم‌افزار موافقت می‌کنید که:

• فقط برای اهداف قانونی و مشروع از نرم‌افزار استفاده کنید
• استخراج داده را مسئولانه و مطابق قوانین انجام دهید
• لایسنس معتبر و فعال داشته باشید (برای استخراج کامل)
• حقوق اشخاص ثالث و شرایط سرویس منابع داده را رعایت کنید

═══════════════════════════════════════════════════════════════════════════════
۳. محدودیت‌ها
═══════════════════════════════════════════════════════════════════════════════

• کپی، توزیع مجدد یا فروش غیرمجاز نرم‌افزار ممنوع است
• مهندسی معکوس یا حذف قفل لایسنس ممنوع است
• استفاده برای استخراج شماره تماس یا داده‌های خصوصی ممنوع است
• نرم‌افزار محصول رسمی دیوار نیست و وابسته به دیوار نمی‌باشد

═══════════════════════════════════════════════════════════════════════════════
۴. سلب مسئولیت
═══════════════════════════════════════════════════════════════════════════════

نرم‌افزار «همان‌طور که هست» ارائه می‌شود. ناشر مسئول خسارات ناشی از
استفاده نادرست، قطع سرویس منبع داده، یا تغییرات API شخص ثالث نیست.
